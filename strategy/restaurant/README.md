## 長期ビジョン（2026-07-19 奏画さん共有）

- **自社レストランブランドの方向性 = 「シズラー（Sizzler）型」レストランを"自社ブランドで"複数展開（チェーン化）**。
  - シズラー型 = **ステーキ＋サラダバー／ビュッフェを軸にしたファミリー向けカジュアルダイニング**（日本で親しまれている業態イメージ）。奏画さん確認済みの定義。
  - 本家Sizzlerのフランチャイズではなく、**"シズラー的な体験"を自社オリジナルブランドで作る**。
- **時間軸: 3年以内（〜2029-07 目安）** にシズラー型ブランドを展開する。
- **Zanzibar もいずれシズラー業態に転換する**（＝シズラー型チェーンの第1号への布石）。
- したがって当面の承継（現状維持）は「転換までの安定運用フェーズ」と位置づける。承継でブランド・オペを壊さず引き継ぎ、その上でシズラー型へリブランドする2段構え。

**ステージ設計（時間軸付き）**:
1. **今〜（最優先）**: Zanzibar を現状維持のまま円滑に承継しきる（人も内装も替えない）
2. **次**: 承継完了・経営が安定したら、Zanzibar をシズラー型へ転換
3. **3年以内（〜2029-07目安）**: シズラー型自社ブランドを軸に複数店展開

> **現在の集中点は明確: ステージ1「Zanzibarを引き継ぐ」に全振り。** シズラー転換・多店舗展開は3年スパンの目標として保持しつつ、今は動かさない。

## 承継の基本スタンス（合意済）

- **人を替えない**: 既存のキーマン・従業員をそのまま引き継ぐ（店の味・オペ・信用の源泉を壊さない）
- **大改装しない**: 古くなった箇所の小規模リフレッシュのみ。ブランド・内装の大幅刷新はしない
- → 承継そのものは「立て直し」ではなく「**確立した事業の円滑な承継**」で進める

## 承継のミッション = 維持 + 収益性改善（2026-07-20 更新）

- **単なる維持ではない。収益性の改善が明確なゴール**。
- Zanzibar 現状: オーナー手取り **月 約100万PKR** → **目標 月300〜500万PKR（3〜5倍）**。業界の良い店は月1,000万PKR。
- 人・内装は触らず円滑に承継したうえで、**客単価・原価率・稼働・オペ効率**で利益を伸ばす。Furvaさんのメニュー開発/ブランディングが効く領域。
- 中長期のシズラー型転換は、収益構造を変える最大の打ち手。
- **大前提: 現状の詳細P/L把握が最優先**（手取り100万の内訳＝売上/原価/人件費/家賃 が分からないと改善レバーを特定できない）。
