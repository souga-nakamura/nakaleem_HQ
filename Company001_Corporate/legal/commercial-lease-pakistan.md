# パキスタン（パンジャブ州）商業不動産の賃貸借 — 立退きリスクと契約防御

作成: 2026-07-30 / 担当: 一郎 / 相談元: 奏画（COO&CFO）
論点: 「商業不動産を契約した後、オーナーから『こういう理由だから出てくれ』と言えるのか」

> ⚠️ 本ファイルは経営判断用の整理。**法的助言ではない**。契約実行前にパキスタン現地弁護士（および法務エージェント aiko）でのレビューを必須とする。条番号・期間は要確認事項として扱う。

---

## 結論（先に）

1. **オーナーは「自分の意思だけ」では追い出せない。** 立退きには **Rent Tribunal（賃貸審判所）への申立て＋法定事由**が必要で、自力執行（鍵交換・電気止め・人を寄せる等）は違法。
2. **ただし「法定事由」に該当すれば追い出せる。しかもその事由の中に「契約期間の満了」が入っている。** ここがパキスタンで最大の落とし穴。**期間満了＝更新権は原則なし**。3年契約なら3年後にオーナーは正当に明渡しを求められる。
3. **さらに「オーナー自身が使う必要が生じた」「建替え・大規模改修する」も法定事由。** つまり「こうこうという理由だから出てくれ」は、**理由の中身によっては通る**。
4. → **当社の防御は「法律」ではなく「契約書」で作る。** 内装に金を入れる事業（ShareLounge 400万PKR／Coffee Shop capex 1,650万PKR）では、**長期期間＋当社側の更新オプション＋未償却内装の補償**を取れているかが投資判断の前提条件。取れないなら投資額を落とすか物件を替える。

---

## 1. 適用法（Lahore = パンジャブ州）

- **Punjab Rented Premises Act, 2009（PRPA 2009）** が、パンジャブ州の都市部における住居用・**商業用**の賃貸借を規律する。Lahore（DHA/Gulberg含む）はこれ。
- 判断機関は **Rent Tribunal**（実務上は指定された司法マジストレート／Rent Controller相当）。第一審の後、**地方裁判所（District Judge）への控訴**が可能。
- 州ごとに別法（例: シンド州は Sindh Rented Premises Ordinance 1979）。**Multan もパンジャブ州なので Zanzibar も PRPA 2009 圏**。

### 契約の形式要件（ここを外すと当社が弱くなる）
- 賃貸借契約は **書面**であることが法定。**印紙（stamp duty）** を貼り、**Rent Registrar への登録**を行う建付け（届出期限は締結後30日程度。要確認）。
- **実務では未登録・口約束・「印紙だけ貼って登録せず」が非常に多い。** 未登録だと紛争時に当社の主張の証拠力が落ちる／登録を怠った側が不利に扱われうる。
- ✅ **当社ルール: 全事業の物件契約は「書面＋印紙＋Rent Registrar 登録」まで完了させる。** 登録費用をケチらない。

## 2. オーナーが立退きを求められる法定事由（PRPA 2009・要旨）

| # | 事由 | 当社にとってのリスク | 対策 |
|---|---|---|---|
| 1 | **賃料の不払い・遅延** | 中（送金・銀行手続のミスでも発生しうる） | 自動送金＋領収/入金証跡の保管。猶予期間（15日等）を契約に明記 |
| 2 | **契約期間の満了** | 🔴 **最大** | 長期期間＋**当社側の一方的更新オプション**（後述） |
| 3 | **オーナー自身（または家族）の bona fide な使用必要** | 🔴 高 | 期間内は主張できない旨を明記。ロックイン条項 |
| 4 | **建替え・取壊し・大規模改修の必要** | 中〜高 | 同上＋改修時の代替場所/補償義務 |
| 5 | **無断転貸（サブリース）** | 🟠 **ShareLounge は要注意** | 「共用ワークスペースとしての第三者利用は転貸に当たらない」旨を明記（下記§4） |
| 6 | **合意した用途以外での使用** | 🟠 中 | 用途条項を広く書く（"co-working / lounge / F&B service" 等を列挙） |
| 7 | **物件の価値・効用を損なう改変／近隣妨害** | 中 | 内装工事の事前承諾を契約時に一括取得（図面添付） |

- 参考: 「オーナー自身の使用」を理由に明渡しを取ったのに実際には使わず他人に貸した場合、旧テナントに救済（再入居請求・補償）が認められる規定がある（要確認）。抑止として使える。
- **自力執行は違法。** 電気・水道の遮断、施錠、私的な立入りは当社側から差止め・刑事告訴が可能。ここは強く出てよい。

### 時間軸（実務目安・要確認）
- 法の建付けは迅速処理（数ヶ月内の決着を想定）。**実務では控訴まで含めて1〜3年**かかることが多い。
- ⇒ 逆に言えば **「争えば時間は稼げる」が、その1〜3年を訴訟に使うのは奏画さんの時間コストが最も高い**。訴訟前提の防御ではなく、**契約書で発生させない**方針を取る。

## 3. 契約に必ず入れる条項（当社標準・チェックリスト）

投資額の大きい順に厳しく適用する（Coffee Shop 1,650万 ＞ ShareLounge 400万）。

- [ ] **期間: 初期3年 → 目標5年**。内装回収期間（Coffee Shop 回収約12〜14ヶ月／実耐用5年）を**確実に上回る**期間。
- [ ] **更新オプションは「当社の一方的権利」**。オーナーの同意条件にしない。更新時の**賃料上昇率を上限固定**（例: 年10%、更新時+10%）。※パキスタンは年10%前後の増額が慣行。
- [ ] **ロックイン（オーナー側）**: 期間中は「自己使用」「建替え」を理由とする解約を主張しない旨を明記。
- [ ] **未償却内装の補償**: 期間内にオーナー起因で明渡しとなる場合、**内装投資額の未償却分＋移転費用＋営業損失**を補償。金額根拠として**工事費の内訳書を契約添付**。→ これが最強の抑止。
- [ ] **物件売却時の承継**: 所有者が変わっても本契約は新所有者を拘束（"lease runs with the land"）。加えて**先買権（Right of First Refusal）**。
- [ ] **用途条項を広く**: co-working / shared lounge / 飲食提供 / イベント / 会員制運営 を列挙。
- [ ] **転貸・第三者利用の明確化**（ShareLounge 必須・§4）。
- [ ] **内装工事の包括承諾**: 図面・仕様を添付して事前承諾を取得。**退去時の原状回復義務の範囲を限定**（造作の残置可否・撤去費負担）。
- [ ] **静穏享有（quiet enjoyment）＋インフラ遮断禁止**: 電気・水道・共用部アクセスの妨害禁止と違約金。
- [ ] **ソーラー/空調室外機/看板の設置権**（ShareLounge は B1F ＝ **屋上使用権を契約で明記**。既存タスク「ソーラー設置可否確認」と直結）。
- [ ] **保証金**: 相場は賃料の2〜6ヶ月（advance含む）。**返還条件・控除項目・返還期限を明記**。パキスタンでは返還トラブルが頻発。
- [ ] **賃料前払い（advance rent）の充当ルール**: 「6ヶ月前払い」等が一般的。前払分が最終期間に充当されることを明記。
- [ ] **紛争解決**: 準拠法パンジャブ州／管轄 Lahore。仲裁を入れるかは弁護士判断（PRPAの専属管轄と衝突しうるため要確認）。
- [ ] **登録**: 印紙＋Rent Registrar 登録を**オーナーの協力義務**として明記（費用分担も）。

## 4. 事業別の固有リスク

### ShareLounge（DHA Phase 3・B1F・工事開始が最短）— 🔴 最優先
- **転貸リスクが構造的にある。** 会員に席を使わせる業態は、契約書の書き方次第で「無断転貸（§2-5）」と主張されうる。
  - → 用途条項に「**会員・利用者への一時的な席の提供は転貸に該当しない**」と明記する。
- **B1F ＝ 屋上（ソーラー）・室外機・排気・看板の権利が本体契約に入っていないと後で詰む。** 管理組合/DHA の承認が必要な場合は「オーナーが取得する義務」とする。
- **⚠️ 現在すでに着工前後の段階。契約書のレビューが工事より後ろになっていないか要確認。**（400万PKRを入れる先の契約が弱いと丸ごと人質になる）

### Coffee Shop（9月物件確定→着工）— 🔴 契約前なので最も打ち手がある
- **capex 1,650万PKR ＝ 予算枠4,000万の41%を1物件に固定する。** 契約期間と更新権が取れない物件は、**立地スコアが1位でも候補から落とす**のが正しい。
- 物件選定基準に「**5年＋更新オプション＋未償却補償が取れるか**」を**立地スコアと並ぶ必須条件**として追加する。→ `Serv001_Zanzibar/coffee-shop/README.md` の立地評価に反映。

### Zanzibar（Multan・8月中旬から承継）— 🟠 承継固有の論点
- 承継対価は無償だが、**店舗の土地建物が誰の名義か・賃借なのか自己所有なのかが未確認**。
  - **賃借の場合**: 契約名義が Saleem Iqbal 個人か Zanzibar Pvt. Ltd. か。個人名義なら**法人への名義変更にオーナーの同意が必要**で、そこで賃料増額を要求されるのが定番。
  - **自己所有の場合**: 承継＝株式/資産の移転で、不動産の権利関係（抵当・共有・相続人）を確認。
- ✅ **8月中旬の承継本格化までに「店舗不動産の権利関係」を確定させる。**（→ TASKS.md に登録）

### Burjan
- 当社が仲介側に立つ事業なので、**上記の知識自体がサービス品質になる**。「契約書のレビューまで面倒を見る仲介」は Zameen（掲載広告モデル）が構造的に提供できない差別化要素になりうる。→ `Serv003_Realestate/business-model.md` の差別化論点に接続。
