## 事業概要

**訓練された質の高いメイド（ナニー）を、雇用主候補に紹介するマッチング事業。** 住み込み不要（日勤のみ）の人材にも対応。差別化の核は「トレーニング済みで質が保証されている」こと（非公式チャネルの未訓練メイドとの差別化）。

## 事業モデルの検討経緯（2026-08-12）

当初は**派遣型（雇用主=Nakaleem、月次マージン課金）**で検討したが、以下の理由で**一時金（紹介料）型**に転換。

- 派遣型は「クライアントとメイドが手を組んで直接契約する（引き抜き）」リスクが構造的に大きく、契約条項だけでは防ぎきれない（パキスタンは訴訟が遅く抑止力が弱い）
- 派遣型は給与立替・待機（ベンチ）要員のコスト・寮/送迎の常時運用など固定費が重く、100名運用でも粗利150万PKR/月程度では教育担当・営業/CS採用を賄うには薄い
- 市場調査（Dubai/Gulf・パキスタン国内）の結果、**主流は一時金（Placement Fee）型**。継続課金より運用が軽く、引き抜き問題も構造的に解消される（紹介後は直接契約になるため、そもそも「奪われる」継続収益がない）

## 確定した事業モデル（2026-08-12）

### 料金体系
| タイミング | 金額 | 備考 |
|---|---|---|
| 面談（弊社スタッフ同席・成約有無に関わらず） | **5,000 PKR**（非返金） | 面談・書類手続きコストの回収。成約時は紹介料に充当（内金） |
| 採用決定時（面談当日その場で決済） | **追加45,000 PKR**（合計50,000 PKR） | その場で意思決定・その場で決済。後日の「裏取引」を防ぐ |

### 引き抜き防止の設計（多層防御）
1. **連絡先の非開示（最重要）**: 入金確認までメイドの連絡先を一切開示しない。面談は弊社スタッフが同席し、Nakaleem管理下でのみ実施。これにより「面談で断って後日直接連絡する」ルートを物理的に遮断する
2. **その場即金**: 分割払いにすると「トライアル期間中に裏で合意」される抜け道が生まれるため、一括即金を採用
3. **再マッチング保証**: 返金ではなく、就業開始から一定期間（例: 30日）以内に不適合なら無料で代替候補を再紹介。返金しないことで質への自信を示しつつ、クライアントの不安を吸収する

### ざっくり資金効果（面談10件→成約4件の想定ファネル）
- 不成約6件 × 5,000 PKR = 30,000 PKR
- 成約4件 × 50,000 PKR = 200,000 PKR
- 合計 230,000 PKR / 面談10件

成約率が読めない立ち上げ初期でも、面接料が最低限のダウンサイド保護になる。
